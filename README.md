Platinum Road is an offline trophy guide and tracker for Grand Theft Auto VI on PlayStation 5. It covers all 55 trophies — 1 platinum, 2 gold, 6 silver, 46 bronze — each with its official name, description and grade, a guide written for this page that names its sources (PowerPyx, Push Square, PSNProfiles/Exophase listings and others), a six-stage roadmap to the platinum with the one potentially missable trophy (Positive Mental Attitude, Chapter 1) flagged up front, and a checklist whose progress is saved in the browser with filters by kind and grade, text search, a spoiler shield for story trophies, and export/import of your progress. It runs entirely from static files in `app/` — no build step, no network.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
